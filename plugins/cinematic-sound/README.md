# cinematic-sound  ·  v1.0.0

Hollywood / Think School sound for a finished picture: reference analysis, an original score composed to the beat grid with real instruments, physics-true SFX, mix and master, earshot QA.

## Install
```bash
claude plugin marketplace add NK-EMPIRE/FS-X-CLAUDE
claude plugin install cinematic-sound@fs-x-claude
```
Restart Claude Code, then use: /score-this

Part of the [FS-X-CLAUDE marketplace](https://github.com/NK-EMPIRE/FS-X-CLAUDE). Update with `claude plugin update cinematic-sound@fs-x-claude`.
